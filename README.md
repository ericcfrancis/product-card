# MyShop - E-commerce Product Cards

A responsive e-commerce product card layout featuring interactive elements like "Add to Cart" and "Like" buttons.

## Features

- Responsive product grid using Bootstrap
- Interactive "Add to Cart" button with animation
- "Like" button that toggles between outlined and solid heart icon
- Clean, modern design with Montserrat font
- Mobile-first approach

## Technologies Used

- HTML5
- CSS3
- JavaScript
- [Bootstrap 5](https://getbootstrap.com/)
- [Font Awesome 6](https://fontawesome.com/)
- [Google Fonts](https://fonts.google.com/) (Montserrat)
